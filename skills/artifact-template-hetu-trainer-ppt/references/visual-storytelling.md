# 生动表达：先判断关系，再决定画面

适用：新课、知识页重排、技术更新，以及用户授权重新设计的页面。仅改某个表格/字号时不扩展设计范围。品牌、字号、图片无框、页脚与安全区继续见brand-and-layout。

## 表达选择

| 内容的核心关系 | 首选表达 | 必须看得懂什么 |
| --- | --- | --- |
| 连续步骤、旅程、逐步生成 | 曲线路线或顺序箭头，加功能图标与短注释 | 起点、顺序、方向、终点、步骤如何衔接 |
| 条件、分支、循环、故障处理 | 分支流程图/回路 | 分支条件、去向、结束或回退条件 |
| 原理、对象的相互影响 | 机制图、部件图或前后状态 | 谁影响谁、输入输出、变化原因 |
| 功能、名词或阶段 | 同风格小插图/准确Logo配短解释 | 图形与知识的对应，而非装饰数量 |
| 选型、参数、限制、配置 | 同维度原生表格 | 每列同一口径，适用条件与例外明确 |
| 软件操作和真实成果 | 当前真实截图、关键区放大、步骤说明 | 操作入口、输入、结果与核验动作 |
| 金句/结论 | 中心大字与语义强调 | 一眼读出核心意思，背景低干扰 |
| 多项互不依赖的要点 | 分组文字或紧凑卡片 | 分类清楚、信息密度合理；不用虚假的流程连接 |

先在内部逐页卡中写明“关系、学员要理解/完成的动作、证据、表达、拆页理由”。不要求把内部设计说明放到幻灯片上，也不要求每页都配图。定义、条款和必要原文可以保留段落。

## 曲线路线的可执行规则

第三版参考：route-and-refresh.pptx第1页，源课程第44页。它是一条贯穿画面的有方向路径，节点散布在曲线内外，通过文字和小图标解释连续生成过程。

1. 先确定输入、处理、选择、输出的实际关系。节点数由内容决定，不固定五步或六图标。
2. 路线跨越内容区，允许起伏、转弯和留白。用箭头/终点指向表达前进，虚实线和颜色有统一含义；避免节点盖住路径或连线穿过正文。
3. 标题、关键动词用深蓝/青绿形成层级。每站优先“动作短标题+一句解释”，长说明可分到下一页，不缩小字号硬塞。
4. 图标紧邻对应步骤，视觉重量、线宽与风格一致；对话、分词、运算、选择、输出等图形必须能解释动作。火箭只是输出示例，不固定用于所有终点。
5. 原生路径、箭头、节点标签保持可编辑。使用当前PPT工具支持的曲线/Bezier；背景和插画独立。不能把整页压成图片交付。
6. 渲染检查路径走向、阅读顺序、图文对应及页脚距离；路线只是表达，不能凭形状暗示没有依据的因果、比例或时间间隔。

## 图标与插画

软件品牌使用联网核实的真实Logo，保持原色和透明度。概念图标优先使用已授权资产或按主题生成透明图标；可一次生成同系列图标再分别裁出，保留原图与提示词。按实际可见轮廓统一大小，避免透明边缘导致忽大忽小。截图不能用生成图伪装，人物照片和产品Logo不凭空重绘。

图标不套装饰框，不加影响透明轮廓的阴影。生成文字错误、伪Logo、风格不一致或失真的图标必须修正。已有路线图若用户明确喜欢，保留其几何和阅读节奏再替换语义，而不是一律重排成卡片。

## 密度与教学节奏

一个页面回答一个主要教学问题；解释、证据、练习可拆成多页。密集内容先改分组、列宽和分段，再考虑拆页；保真任务不删原字，页数固定时在既有范围优化。表格应有足够字号和整齐基线，复杂配置表可按入门/企业、文本/视频拆开。避免连续多页重复同一种卡片版式。

高级感来自有用图形、清楚主次、统一对齐和舒适距离；不是添加更多框、球体、渐变或小字。淡色边角背景不争抢截图、正文和图标。
