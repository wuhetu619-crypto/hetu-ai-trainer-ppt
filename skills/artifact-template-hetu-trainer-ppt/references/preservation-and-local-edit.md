# 原文保真与指定范围编辑

## 内容保留的真实含义

旧PPT默认保留每一页、每一个教学字词、图像、视频、表格和流程；原文与辅助解释分开。不能用“重新梳理”默许删减，也不能只保留图片而丢掉原生文字。原文发现错字、陈旧事实或不当断言时先记录，按用户授权加解释/勘误页；纯形式修改不暗中改写。局部范围优先于全局风格。

用户允许加页时，建立“原页→保留页→新增辅助页”映射。新增页不能冒充原页；原页顺序除明确授权外保留。章节拆分、课纲开发与手册材料只在用户要求时进行。旧课全文保留导致密度高，可增加原文放大页/图例/练习，不能偷偷把条件、例子和边界删除。

## 技术更新授权与保真的衔接

用户明确要求用新技术替换旧内容时，过时事实不要求逐字保留在新版课堂页；保留原文件和内部对照，按[技术更新](technical-refresh.md)记录原页、被替换内容、依据与新页。未授权改动的稳定概念、案例和媒体继续保真。纯形式改稿仍每字保留。用户同时要求“每字保留”和“替换旧内容”且无法协调时，先保留原文、另加更新说明；只有确有依赖冲突才澄清，不把普通研究和例行检查变成审批。

## 编辑前的基线

保留输入文件，确认有效最新版本与实际页序（展示第101页不一定叫slide101.xml）。用presentation.xml和关系定位显示页。记录原生对象ID、文字（含标点、数字和空格）、表格每格文字、位置、裁剪与媒体关系；视频单独记录嵌入字节和播放关系，不能只保留封面。图片内文字不等于原生文字，需要人工/OCR识别范围的说明。

```bash
python3 scripts/pptx_inventory.py source.pptx --slides 101,102 --output selected-baseline.json
```

全套改稿省略--slides；只改两页时不读取其余118页正文。必要共享母版、主题、关系是定位依赖；不能因此顺带改它们。

## 局部修改

- 把用户要求变成页号+对象范围；例如两页的表格，不包含标题、上方知识框、页脚、备注和其他页。
- 从这两页提取小PPT并使用可编辑PPT工具完成表格修改；保持原表每格文字与原生行列。
- 检查两页渲染，尤其字号增加导致的溢出与零碎换行。只把经过验证的table节点/目标对象写回原页。
- 写回时原包其余成员应原样保留；可用下面的压缩成员复制工具，它不解析其他页，不重编码图片/视频。不重导出整套来完成一处修订。

```bash
python3 scripts/extract_reference_pages.py source.pptx selected.pptx --pages 101,102
python3 scripts/patch_pptx_parts.py source.pptx revised.pptx --replace ppt/slides/actual-part.xml edited-slide.xml
python3 scripts/compare_decks.py source.pptx revised.pptx --slides 101,102 --allow-objects 101:8 102:16 --output proof.json
```

actual-part.xml与对象ID必须来自基线；上例是命令结构，不能照抄对象号。patch只接受现有成员的替换，不能私自增加/删除关系。需要新媒体、母版或关系时采用明确的包编辑流程并验证依赖。

## 格式调整的顺序

先检查字体是否安装和实际编码；然后处理行距、段距、内边距与列宽；最后微调框高和位置。换行只加软换行或调整文本框，不能改变原字词。图片去框包括原生描边/效果和紧贴图像的纯装饰底框；保留承载知识的流程框、表格线和截图内部边线。

统一全套页脚时可删除已确认旧页码、旧Logo或元数据对象，必须逐对象记录允许删除的ID与原因；不能用“顶部/底部都删除”的坐标粗筛误删课程原文。只修改两页表格时页脚保持原样。

## 验证范围

`compare_decks.py`逐对象核对原文字，并比较范围外ZIP成员的CRC/尺寸/压缩数据；允许对象清单只放用户要改的对象。表格逐格文字保真。单独获准的旧元数据删除可用--allow-delete，不自动忽略任何教学内容。新加辅助页通过--mapping映射，不能把改了全部页的文件声称只改了两页。

`audit_style.py`检查直接编码字体、加粗、图片描边、Logo/页码位置；继承样式/位图内文字/动态媒体/屏幕可读性须人工核查。新课/全套改稿看所有页，局部任务只渲染相关页，并用范围外字节证明其他页未变。PowerPoint/WPS未实际打开，不能声称播放/动画已通过原生软件验证。
