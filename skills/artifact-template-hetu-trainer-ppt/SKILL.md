# 河图·AI讲师PPT

这是培训师专用PPT技能，面向AI时代的课程开发与课堂实操。适用Agent：ChatGPT（支持技能与所需工具的环境）。从培训讲师和课程开发者的视角理解输入，再组织课程、选择表达、制作课件。目标是让学员理解、判断、动手并迁移；内容详实，页面清晰、生动、规整、有留白。用户当前要求优先于默认规则。

公开版保留河图品牌示例。为其他讲师制作时，先按 [个人化配置](references/personalization.md) 替换真实身份素材；不把吴河图的照片与资历当成其他人的信息。

## 开始工作

1. 读取 `artifact-template.json`、[有效样页索引](references/approved-assets.md)、[品牌与版式](references/brand-and-layout.md)，所有路径相对本skill目录解析。
2. 新课或大幅扩纲读取 [输入与课程开发](references/input-and-course-design.md) 和 [起承转合](references/teaching-flow.md)。局部改稿只读取相关部分，不重新规划整课。
3. 制作时读取 [制作与交付](references/production-and-review.md)，使用当前可用的 [Presentations](plugin://presentations@openai-primary-runtime) 技能处理模板复用、可编辑PPT与渲染。背景、插画使用可用的imagegen工具或技能。
4. `assets/reference.pptx` 是已确认封面参照；其余按有效样页索引复用。保持原始参照不变，在课程副本中修改。不要把封面重复成全套，或用旧页覆盖新确认。

## 输入与持续对话

- 接收主题、简略/详细课纲、知识点、书籍、文稿、网页、论文、旧课件、制度/SOP、访谈/会议记录、录音视频、截图/操作过程、案例、数据、学员作品/问题、培训需求、混合资料与多轮反馈。按实际可读范围处理，不承诺读取不可访问内容。
- 只有主题也能做首版：内部确定合理受众、时长与深度假设，主动研究开发。已有课纲保留主线；简单课纲补齐每章教学链条，不只把章名变成页面标题。
- 合并后续反馈，维护已确认、需修改、待核实记录；局部反馈局部改，保留未要求更改的已确认部分。
- 六问、媒介判断、起承转合、拆页检查由制作方内化，不变成逐项问卷。只有无法合理推断且会实质改变课程的问题才集中询问。用户已要求直接完成时，内部规划后继续。

## 培训内容开发

先明确学员最终能做什么，再安排讲授、例子、练习与评价。每章、每个实质知识单元具备起承转合的教学作用，可跨多页，也可在短单元中合并；不强制四页，不把四个字印在所有页面。

- **起：**用贴近学员的问题、工作情境、故事或现象说明为什么学，连接已有经验。
- **承：**解释概念、机制、步骤、条件，提供清楚的示例或演示。
- **转：**让学员应用、比较、判断、处理变化/错误/例外，并获得反馈；不为反转而编故事。
- **合：**回扣问题，归纳方法与检查标准，安排迁移并衔接下一单元。

逐页内容卡记录：知识来源、章节/知识单元、教学目标、核心内容、起承转合作用、图形关系、表达形式、素材依据、互动、预计时间、讲师提示。参见 [课程开发示例](examples/课程开发示例.json)。关键定义、条件、操作和判断不能只剩口号，用连续页与配套材料承载详实内容。

完整课程默认：封面→固定个人介绍第2页→鱼骨大纲→各章章节页与知识/案例/演示/练习/讲评→综合迁移→结束页。页型按教学需要选择，不为每章机械重复全套；章节数量不固定十章。只做指定样页或局部页面时尊重范围，不自动插入全套固定页。

## 按语义选择表达

| 内容 | 首选表达 |
| --- | --- |
| 软件操作 | 真实截图、局部放大与分步标注；目标、位置、预期结果、检查点 |
| 流程/判断 | 可编辑步骤或分支图；真实顺序、条件与回路 |
| 原理/系统 | 机制图、结构图、概念插画；对象、关系、边界 |
| 故事/人物 | 核实人物照片或史料、场景、时间线；需要时抠图 |
| 成语/典故 | 语义准确的情境插画或连续画面 |
| 名词/工具 | 定义加示例、三图标页或合适数量的并列结构；工具用真实官方Logo |
| 比较/数据 | 同维度比较、原生表格与图表，保留单位口径来源 |
| 金句 | 内容区正中大字，少量重点变色；低干扰的语义品牌背景 |
| 练习/讨论 | 案例、明确任务、用时、提交物、合格标准、反馈 |

图片必须解释知识，不用通用机器人、电路或发光大脑代替语义分析。可参考宝玉插画/知识卡片的表达方法，不强制依赖宝玉安装，不用整页图片取代可编辑文字和图表。

## 固定品牌与可变内容

- 16∶9，蓝绿品牌，思源黑体Heavy标题/Regular正文；字号、坐标、留白见品牌参考。
- 封面沿用确认构图；根据新主题生成主副标题、可选短线主题句与蓝绿晕染背景。保留用户原意，原题能单行就单行，超长先合理提炼而非挤压。背景不生成文字与Logo。
- 河图原版完整课程固定第2页：直接复用 `assets/samples/profile-v6.pptx` 第2页。真实照片、姓名、资历、布局、字号、断行已锁定，不重画人物；课程元数据和页码可变。
- 大纲采用鱼骨中轴，上下交替章节名与概括；轴表达学习顺序，非虚构时间；过密拆总览与分段。
- 章节只保留大标题和一句概括；每章生成功能性主题关系图，蓝绿渐变。“拆解经验”的书籍→步骤→判断只用于对应语义。不要恢复旧01/02/03、黄色产出或额外列表。
- 内容背景复用 `assets/backgrounds/content-circles.png`：边角淡蓝淡青绿大圆形，中央近白干净阅读区；不用整页纯白。同系列少量变化，避免立体球与装饰拥挤。
- 三图标页沿用已确认紧凑布局与底部留白；项目数量不符时换布局，不凑三项。Logo用真实深浅原图，页脚位置统一、页码动态更新。
- 金句/结束页已有规则但未单独确认样页，按规则制作首版，不谎称已锁定成品，也不因此停止整课。

## 核验、拆页、交付

制作必须联网核查外部事实、工具入口、案例和素材，优先官方与一手来源，记录日期与链接。无法联网时说明缺口，先完成独立工作，不编造核验结果。区分真实/生成、原文/解释、公开案例/模拟练习。

文字、表格、图表和逻辑图保持原生可编辑，背景与插画独立。生成界面不冒充真实截图，不能伪造官方Logo、人物真容或运行证据。

文字过小、截图不清、流程拥挤、多个独立教学中心或侵入页脚时主动拆页，优先概念→示例、整体→局部、流程→例外、任务→讲评。硬性页数包含固定页，冲突时提出具体取舍，不偷偷加页或缩字。

正式交付可编辑PPTX、PDF、学员练习材料、讲师备注/参考答案、来源和版本记录。只交本次请求范围；网络演示准备真实截图/关键帧等备用材料。

运行 `scripts/check_package.py` 验证资源；成品可运行 `scripts/audit_deck.py` 检查包结构、画幅、编辑对象和固定讲师信息。这些不替代逐页渲染、阅读和教学审校。仅报告实际完成的生成、软件验证与视觉检查。
