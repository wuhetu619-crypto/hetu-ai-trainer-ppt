# v2.0.0 · 120页课程经验升级

发布日期：2026-10-18。上一公开版本：v1.0.0（2026-10-17）。技术ID和中文显示名不变，本次升级替换当前安装和main内容，历史提交/Release保留可追溯性。

## 本次升级解决的实际问题

| v1/旧工作方式 | v2行为 |
| --- | --- |
| 新课和旧课整理的边界不够明确 | 四种模式区分：新课、保真精修、授权扩充、局部指定对象 |
| 美化中可能摘要化或漏页 | 对原页、每个字、每格文字、媒体关系建基线；扩充用原页映射 |
| 改两页也可能重导出全套 | 提取目标页验证，只替换允许对象；其余压缩成员原样复制 |
| Heavy标题/Regular正文混用 | 可编辑文字统一Source Han Sans SC Heavy并加粗 |
| 图片圆角/底框影响抠图融合 | 图片与照片无外框和阴影，透明轮廓保留；语义框和表格线继续存在 |
| 页脚重复、右上页码/章名混杂 | 左下唯一小Logo、右下唯一实际n / N，旧元数据按ID移除 |
| 第一卡片空洞、底行贴Logo | 按内容计算框高，修正标题正文间距与页脚安全区 |
| 表格小字、对齐不协调 | 浅绿边线/表头、Heavy大字、水平垂直居中、语义断行 |
| 参考分散在多个试稿 | 一个27页原生参照、27张预览、8张公开截图及源页索引 |
| 方法只停留在美观 | 扩展为21类语义表达关系，结合学习契约、验证评分、修订与迁移 |

## 新增和更新文件

- SKILL.md重写为按任务模式与资源路由的入口，保持自动发现。
- design-tokens.json：颜色、画幅、Heavy加粗、字号范围、页脚坐标/间距、图片和表格参数。
- preservation-and-local-edit.md：原页原文保真、局部范围、媒体保留、对象白名单、原页映射。
- expression-patterns.md：21类表达选择及四种教学组织方式。
- brand-and-layout.md、production-and-review.md、approved-assets.md、个人化/输入规范同步更新。
- 五个新增功能脚本：pptx_inventory、extract_reference_pages、patch_pptx_parts、compare_decks、audit_style；另有run_regressions和更新的check_package，原audit_deck继续保留。
- VERSION、版本历史、源码来源JSON、真实任务验收例、安装升级说明和使用说明。

## 保留与退出

保留：中文显示名、技术ID、固定真实个人介绍、深浅Logo、蓝绿气氛、语义封面/章节、鱼骨大纲、淡色圆形内容背景、培训起承转合与真实演示/练习。

退出当前活动包：旧散落samples、讨论archive、旧Regular正文默认、强制图片框/圆角、右上重复页码规则。旧版本只在Git历史和历史Release保留；不并列安装两个可调用版本。

不固化：120页长度、原课程章节数、旧工具年份/产品状态、案例统计和法律断言。纯形式修订不主动改写课程事实；新知识另行联网核查。

## 安装和继续使用

下载完整v2.0.0技能zip并保持同一目录名称；已有个人化身份的使用者先保存自己的配置再合并。作者本机已完成更新，可直接说“使用河图·AI讲师PPT”或显式调用`$artifact-template-hetu-trainer-ppt`。

本地技能与ChatGPT工作区Agent的云端上传不是同一个入口，见[安装与升级](../installation-and-upgrade.md)。
