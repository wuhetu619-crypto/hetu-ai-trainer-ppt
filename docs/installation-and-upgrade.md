# 安装与升级 v3.0.0

## 作者当前ChatGPT桌面

该桌面环境可发现个人skills目录。v3在同一`artifact-template-hetu-trainer-ppt`目录原位替换，保留已登记的主参考与预览，新增补充原生样页和更新说明；显示名继续为“河图·AI讲师PPT”。用技能发现接口核对当前路径、enabled状态及新版描述。不要同时把多个版本的文件夹放在可发现的skills目录。

下载完整发布包后，请支持本地技能的Agent安装完整文件夹并运行check_package.py。已有个人修改时先保存身份素材；升级不要误覆其他人的个人化信息。包内是作者公开示例身份。

模板图库若尚未刷新，可重新打开选择器；在新一轮对话中显式使用`$artifact-template-hetu-trainer-ppt`。制作前让Agent读取当前SKILL.md/VERSION，不以旧会话中缓存的字体规则为准。

## ChatGPT云端与其他入口

本地安装与云工作区Agent的技能上传是两种部署。仓库发布或复制到本机目录不等于上传到网页/手机/云端。若工作区提供技能上传入口，使用完整技能包，并在实际上传成功后核查资源和调用。此项目没有自动跨所有ChatGPT端同步的承诺。

官方资料：[Skills](https://developers.openai.com/plugins/build/skills)、[ChatGPT Agents技能应用示例](https://developers.openai.com/cookbook/articles/chatgpt-agents-sales-meeting-prep)。具体入口以当前账户和客户端能力为准。

## 包和历史

最新包`hetu-ai-trainer-ppt-v3.0.0.zip`只有一个顶层技能目录。当前main与Latest Release指向v3；v1/v2留在Git历史和历史Release用于追溯。旧活动安装退出，历史可审计。
