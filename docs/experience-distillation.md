# 120页课程的经验萃取 → v2可执行规则

不是把聊天记录全部塞进SKILL.md。先区分品牌、教学规律、编辑边界与单课事实，再分为入口、参数、参考、样页和脚本。

| 原课与反馈 | 可复用规律 | 当前落点 |
| --- | --- | --- |
| 所有原页和原字都不能丢 | 美化默认保真；扩展有原页映射，不能摘要替换 | preservation-and-local-edit、inventory、compare |
| 每次只改指定两页 | 实际页序定位、指定对象白名单、范围外压缩记录原样 | patch、compare及真实101/102回归 |
| 图片本来已抠图，套框破坏融合 | 图片无外框/阴影/强制圆角；保留流程和表格的语义框 | tokens.pictures、audit_style |
| 个人介绍已确认 | 固定第2页真实身份、原照和布局，不因主题重排 | reference第2页、instructor.json |
| 右上/右下重复页码 | 一个左下Logo、一个右下n / N；旧元数据逐对象删除 | tokens.footer、audit_style |
| 第31/32页等第一框空洞 | 标题正文间距和框高随内容，外留白与页脚安全区独立 | reference第9/10页、brand-and-layout |
| 第101/102表格字小且不协调 | 大字Heavy、水平垂直居中、浅绿边线/表头、按句意分行 | reference第21/22页、tokens.table |
| 三插图页底行贴Logo | 三图视觉重量、说明和总结基线、底部净空 | reference第7页、footer最小24px参考 |
| 章节只留一句，但不能单调 | 功能性背景解释主题；大标题+一句概括 | reference第16页，按新章语义生图 |
| 演示/访谈/经验必须能落地 | 原话→规则→检查；成品→方法→实操→验证 | reference第17—24页、expression-patterns |
| 长文不能丢又要可读 | 总览+连续原文放大，核对拼接后文字完整 | 源53—57/78—80的规律，不把小字号设新课默认 |
| 最后要学会而非听完 | 学习契约、两次验证、理由评分、迁移总结 | reference第4/20/23/26页、teaching-flow |

各参数是新课起点，局部改稿没有授权的对象不因全局规范而改变。120页、旧课程章节数、旧工具状态、法律判断和统计数据均不固化；主题变化时重新核查。原文发现问题，保留事实边界，不在纯形式修改里暗改。

表达选择器列21类课堂关系，用于选择合适媒介；不是要求每页三栏，也不是每章必须套同样页数。
